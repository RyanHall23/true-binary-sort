# TrueBinarySort

> Sorts the bits of anything. Truly. Pointlessly.

**TrueBinarySort** converts any input into binary, sorts all bits so that `0`s come first, and returns the result as a string.  

It is:
- Deterministic
- Universal (numbers, strings, buffers, objects, arrays, booleans, functions, etc.)
- Totally pointless

## Installation

```bash
npm install true-binary-sort
